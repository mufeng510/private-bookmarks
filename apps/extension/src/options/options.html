🔖 Private Bookmarks Sync

浏览器书签单向同步到你的私有服务器（浏览器 → 服务器，服务器绝不修改浏览器书签）。 服务器地址、Token 等设置保存在浏览器账号中自动同步（Chrome 走 Google 账号 / Edge 走 Microsoft 账号）。

例如：https://bookmark.example.com 或 http://192.168.1.10:8080

⚠️ 当前使用 HTTP 明文连接，Sync Token 将以明文发送。建议在 NAS 上启用 HTTPS（公网访问时必须）。

在网站「设置 → 同步」中创建，只在创建时完整显示一次。

首次安装自动生成随机 ID，可自定义（3-64 位，字母数字开头，可用 . _ -）。本机标识不跟随浏览器账号同步—— 每台设备保留独立数据源，多台设备登录同一账号也不会互相覆盖。重装系统后填回同一个 ID 即可延续数据。

全量校验用于兜底：防止浏览器休眠、事件丢失、网络中断造成的漏同步。

安全说明

  • 服务器地址、Sync Token 等设置保存在浏览器账号的同步存储中（chrome.storage.sync），跟随账号在登录同一账号的浏览器间自动同步。
  • Sync Token 仅发送到你配置的服务器，不会发送给任何第三方。
  • Client ID 与书签快照仅保存在本机（chrome.storage.local），不随账号同步。
  • 扩展只读取书签并上传，绝不会创建、修改、移动或删除浏览器书签。
  • 公网部署务必使用 HTTPS。
